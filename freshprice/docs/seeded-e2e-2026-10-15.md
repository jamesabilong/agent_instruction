# Seeded FP-65 end-to-end suite — 2026-10-15

Run from `fresh-price-front`:

```sh
npm run test:e2e:seeded
```

Requires Docker, Node 20+, dependencies installed in both sibling repositories, and Playwright Chromium (`npx playwright install chromium`). The checked-out backend must include FP-65 and its observation migration. Ports 55466, 4401 and 5179 must be free. No production credentials are needed.

The runner creates its own PostgreSQL 14 container with random credentials, applies all Sequelize migrations, and invokes `platform-backend/tests/seeders/observations.js`. The seeder accepts only the exact localhost test database/port and refuses nonempty application tables. It creates password-hashed operator/member accounts, Ginger/Luya with a Luy-a alias, Muscovado, two Cebu markets, an official current price of ₱42 and historical price of ₱40. Dates use Asia/Manila and stay within the trend window. Quotes use realistic prices, quantities, seller and quality context. These are synthetic fixtures, not claims about current market prices.

Playwright starts the actual backend and Vite on separate test ports, refuses existing servers, and exercises real HTTP/auth/database persistence. API responses come from the real backend. One fault-injection test commits an import with `route.fetch()` and aborts delivery to the browser, then verifies a same-batch retry against persisted rows. Normal pass/failure cleanup removes only the runner's named container and its volumes. Browser traces/screenshots and HTML/JUnit reports are retained. Do not run the normal and seeded suites concurrently because the normal suite clears its report output directory.

The default mocked suite excludes `tests/e2e/seeded`; it remains available through `npm run test:e2e:chromium`. Seeded tests have one worker, no retries, no skips, no fail-fast setting, and forbid focused tests. Every test executes even when an earlier test fails. Filtered `--grep` runs are useful for diagnosis but do not count as a complete run.
